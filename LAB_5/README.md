# Assignment 5: Sequence Classification (RNN, LSTM, GRU)

## Objective
Implement and compare RNN, LSTM, GRU models for sequence classification and analyse their performance using an appropriate evaluation matrix.

## Description
This assignment focuses on sentiment analysis using the IMDB movie review dataset. Three different recurrent neural network architectures are implemented and compared:
1. Simple RNN
2. LSTM (Long Short-Term Memory)
3. GRU (Gated Recurrent Unit)

The models are evaluated based on their validation accuracy and training time to demonstrate the benefits of advanced gating mechanisms in handling long sequences.

## Files Included
* `Assignment_5_Sequence_Classification.ipynb`: The Jupyter Notebook containing the models' implementation and comparison.
* `Assignment_5_Document.docx`: The detailed laboratory report including code, comparison plots, and output screenshots.
