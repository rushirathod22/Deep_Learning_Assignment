# Assignment 4: LSTM for Time-Series Forecasting

## Objective
Develop an LSTM-based model for time-series forecasting using stock-price datasets.

## Description
This assignment implements a Long Short-Term Memory (LSTM) network to predict future stock prices based on a synthetic time-series dataset. 
The process includes data normalization using MinMax scaling, sequence generation, model training, and performance evaluation using Root Mean Squared Error (RMSE).

## Files Included
* `Assignment_4_LSTM_TimeSeries.ipynb`: The Jupyter Notebook containing the full code and execution flow.
* `Assignment_4_Document.docx`: The detailed laboratory report including code and output screenshots.
